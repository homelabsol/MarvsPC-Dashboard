Emergency code

Para sa shop na tumigil dahil sa lisensya (walang internet, sira ang cloud, o may problema ang key). Ibibigay ng owner ang numero na nasa admin page niya; ibigay mo sa kanya ang code. Bubukas ang system nang 3 araw, kahit walang internet. Isang beses lang magagamit ang bawat code.
